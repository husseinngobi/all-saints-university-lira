# All Saints University Lira

Build the All Saints University Lira premium university website and clickable admissions demo as specified in the attached document. Include the full-featured public university website, academic programmes with details, the interactive admissions portal with multi-step application wizard, simulated Ugandan payment flow (MTN Mobile Money, Airtel Money, Visa/Mastercard) with demo receipts, the student portal dashboard with application status timeline, and the university administration review dashboard.

This project was built with [Lovable](https://lovable.dev).
